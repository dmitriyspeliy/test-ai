\# Project vision



We are building a minimal full-stack task manager for local development.



The goal is not to create a large enterprise system, but to build a clean baseline project that can be extended later.



Main entities:

\- Task



Basic operations:

\- Create task

\- List tasks

\- Update task status

\- Delete task



Backend:

\- Java 21

\- Spring Boot

\- PostgreSQL

\- Flyway



Frontend:

\- Next.js

\- TypeScript



Infrastructure:

\- Docker Compose for PostgreSQL
