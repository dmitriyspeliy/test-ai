\# Codex project rules



\## Scope



Work only inside this repository.



Do not modify files outside the current project directory.



Before making large changes, explain the plan.



\## Tech stack



Backend:

\- Java 21

\- Spring Boot

\- PostgreSQL

\- Flyway

\- REST API



Frontend:

\- Next.js

\- TypeScript



Infrastructure:

\- Docker Compose

\- Local PostgreSQL



\## Coding rules



\- Keep code simple and production-like.

\- Do not add authentication unless explicitly requested.

\- Do not add unnecessary frameworks.

\- Prefer clear package structure.

\- Add meaningful comments only where they explain non-obvious decisions.



\## Workflow



For every non-trivial task:

1\. Analyze current files.

2\. Propose a short plan.

3\. Wait for confirmation if files will be changed significantly.

4\. Implement.

5\. Run available checks/build/tests if possible.

6\. Summarize changed files and commands executed.
